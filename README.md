# 📖 Repository Overview

Welcome to my **Cloud Computing Lab & Assessment Portfolio**.

This repository serves as a centralized academic workspace containing all laboratory experiments, assessments, presentations, reports, documentation, and supporting materials completed as part of the **CSA1507 – Cloud Computing** course.

The objective of this repository is to maintain an organized collection of practical work performed during the laboratory sessions while documenting the concepts and technologies learned throughout the course.

---

# 🎯 Repository Objectives

- 📚 Maintain all laboratory experiments in one place
- 📝 Store internal assessments and submissions
- 📄 Preserve laboratory records and reports
- 📊 Archive presentation materials
- 📸 Maintain experiment screenshots
- ☁️ Practice various cloud computing concepts
- 💻 Document Software as a Service (SaaS) applications
- 🚀 Track academic progress throughout the semester
